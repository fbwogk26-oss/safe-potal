개선 요청 사항 (5가지)

1. 조사 프로세스 2단계 워크플로우 (핵심 — 가장 먼저 구현)

지금은 조사를 한 번에 다 입력하는 단일 폼인데, 실제 법정 절차에 맞춰 아래처럼 1단계 유해요인조사 → (조건부) 2단계 증상조사표로 이어지는 흐름으로 바꿔줘.


1단계: 유해요인조사 등록

부서, 작업내용, 부담작업 1호~11호 체크리스트, 작업조건(설비/작업량/작업속도/작업자세 등), 현재 조치사항, 개선계획 등 기존 항목 입력
조사표 마지막에 "해당 작업 근로자 중 근골격계 증상(통증·저림 등)을 호소하는 인원이 있습니까?" 스크리닝 질문(예/아니오 + 해당 근로자 명단 입력) 추가
**"아니오"**를 선택하면 → 해당 조사는 "조사완료(증상없음)" 상태로 바로 종결
**"예"**를 선택하면 → 조사 저장과 동시에 "증상조사 대기" 상태로 전환되고, 스크리닝에서 입력한 근로자별로 2단계 증상조사 항목이 자동 생성됨



2단계: 근골격계질환 증상조사표 (조건부 진행)

1단계에서 "예"로 넘어온 조사 건에 대해서만 근로자별로 증상조사표 입력 화면을 열 수 있게 해줘
항목: 신체부위별(목/어깨/팔꿈치/손목·손/허리/다리·발) 통증 유무, 통증 강도, 통증 빈도, 통증 지속기간, 통증으로 인한 업무 지장 정도 등 표준 증상조사표 구성
대상 근로자 전원의 2단계 입력이 끝나야 해당 조사 건이 "종결" 상태로 바뀌도록 처리
목록 화면에서 "증상조사 대기 중인 건", "증상조사 진행중인 건"을 따로 필터링해서 담당자가 놓치지 않도록 표시



상태값을 다음과 같이 세분화: 진행중 → 유해요인조사 완료 → (증상 없음이면) 종결 / (증상 있으면) 증상조사 대기 → 증상조사 진행중 → 종결
대시보드나 알림 영역에 "증상조사 대기 중인 건수"를 눈에 띄게 표시해서 담당자가 후속조치를 놓치지 않게 해줘


2. 입력/작성 편의


부서/작업명/평가자는 최근 입력값 기준 자동완성 제안
이전 조사 항목을 복사해서 새 조사로 시작하는 "이전 조사 불러오기" 기능
작성 중 임시저장(초안) 기능 — 모달을 닫아도 입력값 유지
여러 근로자/여러 작업을 한 번에 등록할 수 있는 일괄 입력 모드
모바일 화면에서도 입력하기 편하도록 반응형 레이아웃


3. 데이터 관리


등록된 조사 목록을 부서, 위험수준, 진행 상태(위 1번의 세분화된 상태값), 평가일 기준으로 검색/필터/정렬
연도별/부서별로 묶어서 보는 그룹 뷰
엑셀(xlsx)로 일괄 업로드 및 다운로드(내보내기)
조사별로 사진, 도면 등 첨부파일 첨부 가능
조사 이력 수정 시 변경 이력(누가, 언제, 무엇을 바꿨는지) 기록
1단계-2단계가 같은 조사 건으로 연결되어, 상세 화면에서 유해요인조사 결과와 해당 근로자들의 증상조사 결과를 함께 확인 가능하게 해줘


4. 결과 자동 산출 / 보고서


부담작업 체크리스트 결과를 바탕으로 위험수준 자동 산출(현재는 수동 선택만 있음)
증상조사표 응답을 바탕으로 근로자별/신체부위별 위험도 자동 채점
부서별/연도별 위험도 추이를 보여주는 대시보드(막대/꺾은선 차트)
법정 양식에 맞춘 PDF 보고서 자동 생성(유해요인조사표 + 증상조사표 + 개선계획 포함)
개선계획 대비 이행 여부를 추적하는 상태 표시(예: 완료/진행중/지연)


5. 사진 촬영 기반 자세 분석 (신규 기능)


작업자세 사진을 업로드하거나 웹캠으로 촬영하면, 자세 인식(pose estimation) 라이브러리를 활용해 관절 각도를 분석
목/어깨/팔꿈치/손목/허리 등 주요 부위 각도를 계산해서 RULA/REBA 기준에 준하는 위험도 점수를 자동 산출
위험 부위를 사진 위에 시각적으로 하이라이트 표시
분석 결과를 조사 기록(1단계 또는 2단계)에 첨부해서 저장


기술/디자인 가이드라인


기존 사이트의 디자인 톤(카드형 레이아웃, 사이드바 메뉴, 모달 기반 등록 폼)을 그대로 유지해줘
기존 라우팅 구조(/musculoskeletal)와 데이터 모델을 최대한 재사용하고, 새 필드/상태값은 기존 스키마에 확장하는 방식으로 추가해줘
5번(사진 자세 분석)은 클라이언트 사이드에서 처리 가능한 라이브러리(예: MediaPipe Pose 등)를 우선 검토해줘. 서버 비용이나 개인정보(얼굴 등) 이슈가 있으면 촬영 시 얼굴은 블러 처리하거나 신체 스켈레톤만 표시하는 방식도 고려해줘
한 번에 다 만들지 말고 아래 순서로 단계별로 구현해줘: 1) 2단계 워크플로우 → 2) 입력/작성 편의 → 3) 데이터 관리 → 4) 결과 자동 산출/보고서 → 5) 사진 자세 분석
각 단계 완료 후 어떤 파일을 바꿨는지 요약해줘
