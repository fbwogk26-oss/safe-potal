---
name: PDF 결재란/표 좌표 오버레이 보정 방법
description: pdf-lib로 PDF 위에 서명 등 이미지를 특정 표 셀에 겹칠 때, 하드코딩된 %좌표가 어긋나면 실제 파일을 렌더링해 픽셀 스캔으로 재보정
---

여러 문서 유형(예: 안전관리자/보건관리자 보고서)이 같은 함수를 공유하면서 표 레이아웃(칸 개수, 폭, 라벨 유무)이 서로 다르면, 퍼센트 좌표를 하나로 통일하지 말고 문서 유형별로 분리해야 한다.

**Why:** 이전 구현은 두 보고서 타입에 동일한 X 좌표(0.630/0.750/0.870, width 0.120)를 썼지만 실제 표는 유형마다 칸 폭·라벨 칸 유무가 달라 서명 이미지가 셀 밖으로 넘쳤다. 하드코딩 추정치는 눈대중이라 어긋나기 쉽다.

**How to apply:**
1. object storage에서 실제 업로드된 샘플 파일을 받아 `pdftoppm -png -r 150`으로 1페이지를 PNG 렌더링 (150dpi 기준 A4 = 1240×1755px).
2. PIL로 특정 row/col의 픽셀 밝기를 스캔해 어두운 픽셀(임계값 <150) 좌표를 그룹핑하여 표 테두리 선의 정확한 px 위치를 찾는다. 텍스트가 있는 행/열은 오탐이 나므로 반드시 "빈 칸(서명 없는 셀, 라벨 없는 여백 칸)"의 행/열에서 스캔해야 정확하다.
3. 격자 오버레이(빨간/초록 선 + 좌표 라벨)를 그려 이미지로 직접 눈으로 검증한 뒤 최종 좌표를 percentage로 변환한다 (px / page_px_width, px / page_px_height).
4. pdf-lib는 좌하단 원점이므로 top-down %에서 `yBottom% = 1 - bottom_top_down%` 로 변환.
5. 수정 후 반드시 실제 샘플 PDF에 테스트 이미지를 합성해 다시 렌더링, 크롭해서 눈으로 셀 안에 들어가는지 확인 후 커밋.
